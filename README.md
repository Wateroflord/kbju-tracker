# КБЖУ Трекер — как получить APK

Сборку делает GitHub, бесплатно и в облаке. Устанавливать на компьютер ничего не нужно.

## 1. Загрузить проект на GitHub (один раз)

1. Распакуй архив `kbju_tracker.zip` на компьютере.
2. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
3. Справа вверху нажми **+** → **New repository**.
   Имя: `kbju-tracker`, выбери **Private**, нажми **Create repository**.
4. На странице репозитория нажми ссылку **uploading an existing file**.
5. Открой распакованную папку `kbju_tracker`, выдели **всё её содержимое**
   (папки `.github`, `assets`, `lib`, `tools` и файлы) и перетащи в окно браузера.
6. Внизу нажми **Commit changes**.

## 2. Дождаться сборки

1. Открой вкладку **Actions** в репозитории. Если GitHub спросит, включить ли Actions, — включи.
2. Там появится сборка **Build APK**. Она идёт примерно 5–10 минут.
3. Когда появится зелёная галочка, открой её. Внизу, в блоке **Artifacts**, нажми
   **KBJU-Tracker-APK** — скачается zip, внутри лежит `app-release.apk`.

## 3. Установить на телефон

1. Перекинь `app-release.apk` на телефон (через кабель, Telegram «Избранное», Google Диск).
2. Открой файл. Android попросит разрешить установку из этого источника — разреши.

## 4. Подключить распознавание еды по фото

1. Открой https://aistudio.google.com/apikey и войди в Google-аккаунт.
2. Нажми **Create API key**, скопируй ключ.
3. В приложении: вкладка **Профиль** → блок **Google Gemini** → вставь ключ → **Проверить**.

## Если что-то пошло не так

- **Во вкладке Actions пусто.** Значит, папка `.github` не загрузилась. Нажми
  **Add file → Create new file**, в поле имени напиши `.github/workflows/build.yml`,
  вставь содержимое этого файла из архива и нажми **Commit changes**.
- **Сборка с красным крестиком.** Открой её, нажми на шаг с ошибкой, скопируй текст
  ошибки и отправь его Claude — он поправит код.

## Обновления

Загрузи изменённые файлы в репозиторий так же, как в шаге 1. Сборка запустится сама.
Новый APK ставится поверх старого, данные в приложении сохраняются.
